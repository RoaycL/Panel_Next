# v0.0.62

## 登录与同步

- 修复扩展经常“掉线”需要重新登录的问题：令牌刷新请求丢失或多个页面同时刷新时，不再误判为会话失效而注销设备。
- 公共页面和网页标签页中过期的设备令牌会自动刷新，不再因旧令牌请求失败。

## 组件

- 按 Esc 关闭组件放大视图后，组件周围不再残留黑色焦点框。

## 其他

- 仓库更名为 RoaycL/Panel_Next，README、关于页、隐私与支持文档及扩展更新检查链接已同步更新；Docker 镜像名不变（ghcr.io/roaycl/panel-next）。

## 升级提示

- 此版本为测试版，无数据迁移；Docker 与二进制部署建议升级以获得登录修复。
